# 음성 확인 방법 (5분)

Claude Code는 소리를 들을 수 없어서, 실제로 소리가 나는지·말을 알아듣는지는 직접 확인해야 합니다.
아래 순서대로 하면 5분 안에 끝납니다. **debug 빌드**에서는 화면의 "음성 안내" 카드 제목 옆에
상태 칩("말하는 중", "듣는 중", "들은 말: 응")이 떠서 눈으로도 확인할 수 있습니다.

## 0. 준비 (1분)

1. 에뮬레이터 실행: Android Studio 장치 관리자에서 `Pleos_API34` 실행
   (또는 명령 `emulator -avd Pleos_API34 -no-snapshot -cores 2 -no-boot-anim`)
2. Windows 작업 표시줄의 스피커 아이콘 → 볼륨이 0이 아닌지, 출력 장치가 맞는지 확인
3. 에뮬레이터 오른쪽 도구 막대의 볼륨 올리기 버튼을 몇 번 눌러 둔다
4. 에뮬레이터 도구 막대 `…`(Extended controls) → **Microphone** →
   **"Virtual microphone uses host audio input"** 켜기 (노트북 마이크를 에뮬레이터 마이크로 사용)
   - Windows가 마이크 권한을 물으면 허용

## 1. pleos 앱 (실연동) — 소리 확인 (1분)

1. 앱 목록에서 **차근차근** 실행 (debug 빌드 설치 상태)
2. 홈 오른쪽 위 **시동 켜기**
3. 확인할 것
   - 노트북 스피커에서 브리핑 음성이 들린다
   - "음성 안내" 카드 옆 칩이 **말하는 중** → 말이 끝나면 사라진다
   - 칩 대신 "음성 엔진 없음 · 화면 안내"가 보이면 소리가 나지 않는 상태 → 6번 참고

## 2. mock 앱 (데모) — 소리 확인 (1분)

1. 앱 목록에서 **차근차근 데모** 실행
2. 데모 시나리오 **겨울 아침** → **시동 켜기**
3. 1번과 같이 소리와 칩을 확인. 마지막에 "겨울 출발 준비 켤까요?"로 끝나면 칩이 **듣는 중**으로 바뀐다
   → 노트북 마이크에 **"응"** 이라고 말하기 → 칩이 **들은 말: 응** 으로 바뀌고
   위쪽 안내 줄에 "시트 열선 … 켰어요"가 뜨면 음성 인식까지 성공

## 3. 등화 점검에서 "켜졌어" 말하기 (1분)

1. 아래 탭 **등화 점검** → **등화 점검 시작**
   (pleos 앱은 주차 상태여야 시작됩니다. 기어가 P이거나 주차 브레이크가 채워져 있어야 함 — 아래 5번)
2. "제가 전조등(하향)을 켤게요. 켜졌는지 확인해 알려 주세요." 같은 안내가 끝나면 칩이 **듣는 중**
3. 마이크에 **"켜졌어"** 또는 **"안 켜졌어"** → 칩이 **들은 말: …** 으로 바뀌고 다음 등으로 넘어가면 성공
4. 6초 안에 말하지 않으면 칩이 **못 들었어요**로 바뀌고, 버튼으로 답하면 됩니다

## 4. 결과 적는 법

| 확인 | pleos 앱 | 데모 앱 |
|---|---|---|
| 시동 켜기 후 소리가 들림 | 예 / 아니오 | 예 / 아니오 |
| 칩 "말하는 중" 보임 | | |
| "응" → "들은 말: 응" | | |
| 등화 점검 "켜졌어" → 다음 단계 | | |

## 5. 주차 상태 만들기 (pleos 앱 등화 점검·점검표용)

Virtual Console(에뮬레이터 왼쪽 차량 화면 또는 브라우저의 Virtual Console 페이지)에서 기어를 **P**로 둡니다.
에뮬레이터의 주차 브레이크 값은 항상 "해제"라서 기어 P가 유일한 방법입니다.

## 6. 소리가 안 날 때 — 로그 보기

명령 프롬프트에서:

```
adb logcat -s ChageunVoice ChageunTts ChageunStt
```

- `[Pleos TTS] 말하기 요청` → `[Pleos TTS] 재생 시작` → `[Pleos TTS] 재생 완료` 가 보이면 앱은 정상 재생한 것
  → Windows 볼륨·출력 장치, 에뮬레이터 볼륨을 확인
- `Pleos TTS initialize 실패` 또는 `응답 없음` → 앱이 안드로이드 기본 TTS로 바꿔 시도함.
  `[Android TTS] ...`도 없거나 "음성 엔진 없음"이면 이 에뮬레이터에는 쓸 수 있는 음성 엔진이 없는 것
- `[Pleos STT] 인식 결과: 없음 (…)` → 마이크 입력이 들어오지 않음. 0-4번 마이크 설정을 다시 확인

재생 중인지 시스템 쪽에서 보려면(말하는 동안 실행):

```
adb shell dumpsys audio | findstr /C:"state:started" /C:"AudioFocus"
```

`state:started` 줄이 보이면 그 순간 실제로 소리를 내보내는 중입니다.
